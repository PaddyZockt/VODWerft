# Beispiel-Konfiguration

Kopiere diesen Ordner an einen eigenen Ort und ersetze die Platzhalter (`DEIN-KANAL`, Links, Texte).
Die Dateien mit `description` sind Beschreibungsvorlagen fuer YouTube, die `yaml`-Dateien sind
Aufnahmeprofile (Ordner, Tonspuren, Schnittregeln). Echte Zugangsdaten gehoeren nie in diese Dateien.
